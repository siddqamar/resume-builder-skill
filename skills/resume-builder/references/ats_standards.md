# ATS Optimization Standards

## Formatting

- Use plain text or simple Markdown that can be converted to PDF without complex tables or images.
- Use standard section headings such as `Professional Experience`, `Education`, and `Skills`.
- Use common fonts when exporting to PDF.
- Avoid graphics, charts, columns, and complex tables.

## Keyword optimization

- Extract the most important technical and soft skills from the job description.
- Integrate supported keywords naturally into the professional summary and experience bullets.
- List relevant supported keywords explicitly in the Skills section.
- Do not add a keyword merely because it appears in the job description if the source resume does not support it.

## Bullet point structure

Use the Google XYZ formula when the evidence supports it:

`Accomplished [X] as measured by [Y], by doing [Z].`

Example:

`Increased user retention by 20% (Y) by implementing a new onboarding flow (Z) using React (X).`

## Personalization strategy

1. Analyze the job description and separate required qualifications from nice-to-haves.
2. Map the requirements to evidence in the source resume.
3. Rewrite the summary to align with the target role and supported evidence.
4. Prune or de-emphasize experiences that do not contribute to the target role.
