# ATS Optimization Standards

To ensure a resume is ATS-friendly, follow these guidelines:

## 1. Formatting
- **File Type:** Use Plain Text or simple Markdown that can be easily converted to PDF without complex tables or images.
- **Headers:** Use standard section headers (e.g., "Professional Experience", "Education", "Skills").
- **Fonts:** Avoid non-standard fonts. Stick to basics if exporting to PDF.
- **No Graphics:** Do not use images, charts, or complex tables.

## 2. Keyword Optimization
- **Job Description Analysis:** Identify the top 5-10 technical and soft skills mentioned in the job description.
- **Keyword Placement:** Naturally integrate these keywords into the "Professional Summary" and "Experience" bullet points.
- **Skill Section:** Ensure the "Skills" section explicitly lists relevant keywords found in the JD.

## 3. Bullet Point Structure (Google XYZ Formula)
- Accomplished [X] as measured by [Y], by doing [Z].
- Example: "Increased user retention by 20% (Y) by implementing a new onboarding flow (Z) using React (X)."

## 4. Personalization Strategy
1. **Analyze JD:** Extract key requirements and "nice-to-haves".
2. **Map Master Resume:** Select the most relevant experiences from `master_resume.json`.
3. **Rewrite Summaries:** Tailor the "Professional Summary" to align with the specific role's goals.
4. **Prune Irrelevant Info:** Remove or de-emphasize experiences that do not contribute to the target role.
